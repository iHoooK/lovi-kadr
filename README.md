# ЛовиКадр

Локальное приложение для Windows: снимки экрана, длинные скриншоты, аннотации и запись MP4-видео. Без аккаунтов, рекламы и облака.

## Установить готовую программу

На странице релиза GitHub скачайте `LoviKadr-Setup-x64.exe`, запустите его и следуйте шагам установщика. Это один файл, который можно отправить любому пользователю Windows 10 (22H2) / 11 x64.

По умолчанию программа устанавливается в `C:\Program Files\LoviKadr`, поэтому Windows запросит права администратора. В мастере установки можно по желанию создать значок на рабочем столе и включить запуск ЛовиКадра при входе в Windows; оба пункта изначально выключены. На странице лицензии дано краткое объяснение MIT и полный текст условий.

Если старая версия была установлена в `%LOCALAPPDATA%\Programs\LoviKadr`, сначала удалите её через «Установленные приложения» Windows, а затем запустите новый установщик. Снимки, видео и пользовательские настройки при удалении не стираются.

Если запись видео не запускается, установите [Microsoft Visual C++ Redistributable x64](https://learn.microsoft.com/en-us/cpp/windows/latest-supported-vc-redist). В остальном .NET пользователю не нужен: он уже включён в установщик.

Portable-вариант `LoviKadr-Portable` работает без установки, но его нельзя разбирать: переносите всю папку, а не только `LoviKadr.exe`.

## Обновить программу

Начиная с версии **0.1.1**, откройте **Настройки → О программе → Проверить обновления**. Проверка выполняется только по нажатию кнопки и обращается к публичным GitHub Releases репозитория `iHoooK/lovi-kadr`. Аккаунт и токен GitHub не нужны.

Если найдена новая версия, установленная программа предложит **«Скачать и установить…»**. Установщик скачивается с GitHub и проверяется по размеру и SHA-256 из метаданных релиза. Затем подтвердите установку и запрос прав администратора Windows, пройдите мастер и запустите программу с его последней страницы. Установка использует текущую папку программы; настройки, история, снимки и видео сохраняются. Останавливайте запись и захват, сохраняйте изменения настроек и закрывайте редактор до установки. При отмене скачивания или запроса прав программа продолжает работать.

Portable-версия показывает наличие обновления и ссылку на релиз. Скачайте `LoviKadr-Portable-x64.zip`, закройте программу и распакуйте архив в новую папку. Настройки и история находятся отдельно в `%LocalAppData%\LoviKadr` и будут доступны новой версии.

Версию **0.1.0** нужно один раз обновить вручную новым установщиком: в ней ещё нет проверки обновлений. Инструкция для автора по публикации новых версий — [RELEASING.md](RELEASING.md).

## Собрать из исходного кода

Нужны только три инструмента:

1. [Git for Windows](https://git-scm.com/download/win) — в установщике оставьте пункт **Git Bash Here**.
2. [.NET SDK 10 для Windows x64](https://dotnet.microsoft.com/en-us/download/dotnet/10.0) — скачайте именно **SDK**, не Runtime.
3. [Inno Setup 6](https://jrsoftware.org/isdl.php) — создаёт готовый установщик `.exe`.

Скачайте исходники кнопкой **Code → Download ZIP** и распакуйте их либо выполните:

```bash
git clone git@github.com:iHoooK/lovi-kadr.git
cd lovi-kadr
```

## Две команды

Откройте **Git Bash** в корне проекта. Здесь нужны только две команды.

### Выпускная сборка: установщик и portable-версия

```bash
bash scripts/build-release.sh
```

Создаёт `release/LoviKadr-Setup-x64.exe` — установщик для пользователей, `release/LoviKadr-Portable/` — переносную версию, её архив `release/LoviKadr-Portable-x64.zip` и `release/SHA256SUMS.txt` — контрольные суммы. Используйте её, когда хотите передать программу другому человеку или проверить финальную поставку. Папка `release` создаётся заново и не попадает в GitHub.

### Локальный запуск для проверки кода

```bash
bash scripts/run-local.sh
```

Собирает Debug-версию программы для `x64` вместе со всеми нужными файлами и сразу открывает её настройки. Установщик и папка `release` при этом не создаются. После изменения кода закройте ЛовиКадр и повторите ту же команду.

Если после команды окно не появилось, значит уже запущен другой ЛовиКадр: программа специально работает в одном экземпляре и передаёт команду ему. Закройте его через значок в системном трее и выполните `bash scripts/run-local.sh` ещё раз.
