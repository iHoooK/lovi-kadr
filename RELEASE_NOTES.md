# ЛовиКадр 0.1.1

- Добавлена ручная проверка обновлений: **Настройки → О программе → Проверить обновления**.
- Установленная программа скачивает новый установщик с GitHub, проверяет размер и SHA-256 и предлагает запустить мастер установки.
- Скачивание можно отменить. При отмене запроса прав администратора программа продолжает работать.
- Во время записи, захвата или при открытом редакторе установка откладывается, чтобы можно было закончить работу.
- Portable-версия показывает новую версию и открывает страницу релиза для скачивания архива.
- Номер версии установщика берётся из приложения; в выпуск включены portable-архив и контрольные суммы.
- Обновлена политика приватности: проверка выполняется только по команде пользователя, снимки и видео не передаются.

**Установка:** скачайте `LoviKadr-Setup-x64.exe` и запустите его. Для обновления версии 0.1.0 установите этот выпуск вручную поверх текущей установки в Program Files. Настройки и созданные файлы сохраняются.

**Без установки:** скачайте `LoviKadr-Portable-x64.zip` и распакуйте всю папку. Нужны Windows 10 (22H2) / 11 x64.
