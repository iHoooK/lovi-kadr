# ЛовиКадр 0.1.2

Локальная программа для Windows: снимки экрана, длинные скриншоты, аннотации и запись MP4-видео. Работает в трее и сохраняет файлы на вашем компьютере. Без аккаунтов, рекламы и облака.

## Что нового

- Исправлена ошибка, из-за которой во время записи видео нельзя было взаимодействовать с игрой или браузером.
- Теперь во время записи можно нажимать кнопки, вводить текст, играть в браузерные игры и прокручивать страницы. Свободные участки экрана внутри и снаружи рамки пропускают клики к открытым приложениям.
- При старте записи фокус клавиатуры возвращается окну под выбранной областью. Если перед записью использовался инструмент рисования, программа переключается в режим выбора, чтобы можно было сразу работать с приложением.
- Кнопки записи и управление рамкой в режиме выбора больше не забирают фокус клавиатуры у игры или браузера. Перемещение и изменение размера рамки, пауза, остановка и инструменты пометок остаются доступными.

## Какой файл скачать

| Файл | Для кого | Что делать |
|---|---|---|
| `LoviKadr-Setup-x64.exe` | Хочу обычную установку | Запустите установщик и следуйте мастеру. Стандартная папка — `C:\Program Files\LoviKadr`. Подтвердите запрос прав администратора Windows. |
| `LoviKadr-Portable-x64.zip` | Хочу запускать без установки | Распакуйте весь архив и запустите `LoviKadr-Portable/LoviKadr.exe`. |
| `SHA256SUMS.txt` | Хочу проверить целостность загрузки | Сравните SHA-256 скачанного файла с указанным значением. Для обычного запуска скачивать этот файл не нужно. |

**Требования:** Windows 10 (22H2) / 11 x64. .NET уже включён в поставку. Если запись видео не запускается, установите [Microsoft Visual C++ Redistributable x64](https://learn.microsoft.com/en-us/cpp/windows/latest-supported-vc-redist).

В portable-поставке не переносите EXE отдельно: все файлы и папки должны оставаться рядом. Не запускайте приложение изнутри ZIP. Автоматические архивы **Source code** содержат исходники, а не готовую программу.

## Первый запуск

- Запустите ЛовиКадр: значок появится в системном трее.
- Нажмите на значок и выберите снимок области, видео или длинный снимок.
- Для записи видео выделите рамку и нажмите «Начать запись». После этого можно работать с игрой или браузером. Для сохранения нажмите «Остановить и сохранить» или `Ctrl+Shift+PrintScreen`.
- Папки сохранения, звук, микрофон и горячие клавиши настраиваются в настройках. Для выхода используйте меню значка в трее.

## Обновления и сохранение данных

В версии 0.1.1 и новее проверка обновлений доступна в **«Настройки → О программе → Проверить обновления»**. Проверка запускается только по нажатию кнопки. Установленная программа скачивает и проверяет установщик, затем предлагает запустить мастер установки. При обновлении Windows запросит права администратора. Если отменить запрос, программа продолжит работать.

**При переходе с версии 0.1.0 один раз установите новый выпуск вручную поверх прежней программы.** Перед ручным обновлением закройте ЛовиКадр через трей. Если прежняя версия установлена в `%LOCALAPPDATA%\Programs\LoviKadr`, сначала удалите её через «Установленные приложения» Windows, затем установите новый выпуск.

Перед обновлением завершите запись и захват, сохраните изменения настроек и закройте редактор. Настройки, история, снимки и видео сохраняются.

Portable обновляется распаковкой нового архива в отдельную папку. Настройки и история обеих поставок находятся в `%LOCALAPPDATA%\LoviKadr`; созданные изображения и видео — в выбранных вами папках.
